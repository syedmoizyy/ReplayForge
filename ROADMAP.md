# Roadmap

1. Harden deterministic capture and replay correctness, recovery, and bounded execution.
2. Complete declarative fault adapters and golden divergence fixtures.
3. Add authentication, trace redaction, retention controls, and deployment guidance.
4. Measure replay performance on documented environments and optimize only observed bottlenecks.
5. Package the four-screen local investigation journey for an initial release.

Hosted multi-tenancy, production traffic interception, arbitrary worker execution, and generalized observability remain out of scope for the MVP.
