# Code of Conduct

We are committed to a respectful, harassment-free project for everyone.

Be constructive, assume good intent while evaluating evidence, respect privacy, and focus criticism on ideas and code. Harassment, discrimination, threats, doxxing, and sustained disruption are unacceptable in project spaces.

Maintainers may edit or remove harmful contributions and temporarily or permanently restrict participation. Report conduct concerns privately using the contact process in `SECURITY.md`; include enough context for a fair review. Maintainers will protect reporter privacy as far as practical and respond proportionately.

This policy applies in repository discussions and other spaces where someone represents ReplayForge.
